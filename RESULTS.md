# Results: Model Comparison and Agent Testing

## What was tested

Two different approaches to the same question -- does a patient's
immunization record satisfy a state's school entry requirements:

1. **Direct model comparison** -- California, using Gemini and Llama 4
2. **Agentic, tool-based approach** -- Washington, using an ADK agent
   with function-calling tools, tested on one patient

All patient data used in this project is synthetic, generated by
Synthea. No real people's data is involved anywhere in
this testing.

## Part 1: Model comparison results (California)

### Method
Gemini and Llama 4 were each given the same 50 synthetic patients and
California's requirements, and asked to determine compliance per
disease directly, including any age/interval reasoning.

To check their answers, we calculated the correct answer separately
using plain date math (`dose_validity_tool.py`), just working out compliance directly from each patient's dose
dates and California's documented rules.

One requirement was left out of scoring: the 7th-12th grade Pertussis
Tdap booster, since checking it correctly means knowing a patient's
actual school grade, which this data doesn't include.

### Results

| Model | Checks scored | Correct | Accuracy |
|---|---|---|---|
| Gemini | 500 | 497 | **99.4%** |
| Llama 4 | 500 | 495 | **99.0%** |

### Per-class metrics

**Gemini:**
| Status | Precision | Recall | F1 |
|---|---|---|---|
| met | 100.0% | 100.0% | 100.0% |
| missing | 100.0% | 99.0% | 99.5% |
| not_applicable | 100.0% | 100.0% | 100.0% |
| partial | 97.5% | 100.0% | 98.7% |

**Llama 4:**
| Status | Precision | Recall | F1 |
|---|---|---|---|
| met | 97.3% | 90.0% | 93.5% |
| missing | 100.0% | 100.0% | 100.0% |
| not_applicable | 100.0% | 100.0% | 100.0% |
| partial | 96.7% | 99.2% | 97.9% |

### What the remaining errors look like
- Gemini's 3 errors were all the same pattern: marking Pertussis
  "partial" when the correct answer was "missing"
- Llama 4's 5 errors included 4 tied to a single patient, where it
  marked several diseases "partial" instead of "met" -- likely one
  mishandled exception check for that patient, not five separate
  mistakes

Both models did very well here. Gemini was slightly more accurate and
more consistent across categories; Llama 4's errors were more
concentrated around one type of exception handling.

## Part 2: Agent test results (Washington)

### Method
Unlike the direct-comparison approach, the Washington agent doesn't
work out dates itself. It calls two tools: one to look up a patient's
dose history by name, and one that does all the date and interval math
directly (the same logic used above for California). The agent's job
is to call these tools, apply the state's documented exceptions, and
give a final answer.

### Result
Tested on one synthetic patient (Reynaldo722 Beatty507, a
well-vaccinated child with a complete dose history). The agent:
- Called both tools correctly for all 9 applicable diseases
- Correctly figured out that no dose-reduction exceptions changed the
  outcome for this patient
- Got every single disease right, matching what we calculated directly
  as the correct answer
- Gave a clean, structured JSON summary alongside its plain-language
  explanation, so results can be checked programmatically

This is one tested case, not a scaled-up accuracy number like the
California comparison above.
